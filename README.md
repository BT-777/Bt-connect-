# BT CONNECT

A starter local-business discovery app built with React + Vite.

## Run
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Vite.

## Included
- Home dashboard
- Search and category filters
- Business cards
- WhatsApp contact button
- Save businesses
- Add/publish business form
- BT CONNECT profile/contact page
- Mobile-first responsive UI
